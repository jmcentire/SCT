## Installation Instructions

### From GitHub

```bash
# Clone repository
git clone https://github.com/yourusername/forced_rank.git
cd forced_rank

# Install package
pip install -e .

# Or install with dev dependencies
pip install -e ".[dev]"
```

### From PyPI (after publishing)

```bash
pip install forced-rank
```

## Quick Start After Installation

```bash
# Run main analysis
python scripts/run_analysis.py

# Or use Python API
python -c "from forced_rank import run_simulation, print_results; \
           results = run_simulation(use_bias=True, num_simulations=100); \
           print_results(results, 'Biased')"
```
